# 飞书（feishu）

官方插件：用**你自己的飞书账号**登录，让模型读取你的飞书文档和群消息。**只读**，不会发消息、不会改文档。

基于飞书官方命令行 [lark-cli](https://github.com/larksuite/cli)。账号令牌由 lark-cli 保存在系统钥匙串里，插件和应用都不接触、不保存任何令牌。

## 使用

1. 电脑上装好 `lark-cli`（需要 Node.js）：`npx @larksuite/cli@latest install`。
2. 设置 → 插件 → 飞书，依次点：
   1. **初始化应用配置**（首次使用）：按输出里的链接在浏览器里完成；
   2. **登录飞书**：输出里有授权链接，在浏览器里打开并同意；
   3. **完成登录**：回到这里点一下。
3. 状态变成“正常”后，直接跟模型说“读一下这个文档 https://…”或用命令：
   - `/feishu-doc 文档链接`
   - `/feishu-chat 群名关键字 最近三天`

## 隐私和安全

- 读到的内容会作为工具结果发给你当前选择的模型厂商。所以这个插件的工具被标记为**私密工具**：每次调用都会弹窗确认，不能设为“本会话总是允许”。
- 只放行名字里是“读取类”动词（fetch / list / search / get…）且不含“写入类”动词（send / create / update / delete…）的 lark-cli 命令，并强制使用你的用户身份；不允许传 `--output`、`--file`、`--yes` 这类参数。
- 文档和聊天里的文字可能带有恶意指令，技能里已经要求模型把它们当数据看待，但你仍应留意模型接下来的操作请求。
- 登录时授予的权限由 lark-cli 的 `--recommend` 决定（常用权限）。想要更少或更多，可以在终端里自己运行 `lark-cli auth login` 选择。

## 状态

这是第一版：**登录流程和读取命令的参数还没有在真实飞书租户里完整验证过**。命令和参数名由模型通过 `feishu_help` 现查，登录状态的判断也基于对 lark-cli 输出的推断；如果状态显示不准或登录步骤卡住，请把 “登录飞书” 按钮的输出贴给我们。
