# filesystem

把 MCP 官方的文件系统服务器（`@modelcontextprotocol/server-filesystem`，这里固定在 2.2.0）接进 Mosaic，
作为“MCP 插件能用”的官方示范：不需要账号，只需要本机有 `npx`。

- `mcp`：用 `npx -y` 启动服务器，目录由设置里的“允许访问的目录”决定。第一次运行要联网下载，所以连接时限是
  120 秒，连接过程中能在插件详情里看到 npm 的输出；公司代理 / 镜像环境见 docs/usage.md。
- **风险档位**：这个服务器既能读也能写文件，所以清单里**没有**声明 `risk: read`，每次工具调用都会先询问你。
  （对比 `echo-mcp`：它的 `ping` 是只读、无参数的，所以能在详情页里“试调用”。）
- `requires`：声明依赖 `npx`，缺失时在插件页提示；`network`：只是确认页上的声明，应用不会拦截。

安装：设置 → 插件 → 市场 → 文件系统，点“安装”，在设置里选一个目录。
